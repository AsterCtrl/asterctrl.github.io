# AsterCtrl Documentation

Chinese-first, i18n-ready website for the native Linux and Zephyr control
framework. Technical reference sources live beside the core Implementation in
`AsterCtrl/AsterCtrl`; this repository is the public documentation shell.

```sh
npm ci
npm run build
npm start
```

The site builds all configured locales. Documentation describes implemented
behaviour only when a test, generated report, or build artifact supports the
claim.
